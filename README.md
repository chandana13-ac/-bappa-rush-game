# 🐘 Bappa Rush: The Great Festival Challenge

A Ganesh Chaturthi-themed 3D browser game where players take part in different festival preparation challenges before the celebration begins.

🎮 **Play the game:**  
https://remix-bappa-rush-the-great-festival-challenge-7025.ai.studio

## 🎯 Game Overview

In Bappa Rush, the player takes the role of a festival volunteer preparing for a grand Ganesh Chaturthi celebration.

The game features a festival courtyard and multiple mini-games based on traditional festival activities.

The goal is to complete the festival challenges and prepare everything before time runs out.

## 🕹️ Mini-Games

The game includes five festival-themed challenges:

1. 🪔 **Diya Dash** — Light the festival diyas.
2. 🎨 **Rangoli Recall** — Memorize and recreate a rangoli pattern.
3. 🍬 **Modak Factory** — Catch and shape modak offerings.
4. 🥁 **Dhol Echo** — Follow the rhythm of the festival drums.
5. 🌼 **Pandal Perfect** — Decorate the festival stage.

## 🎮 Controls

- **W / A / S / D** or **Arrow Keys** — Move
- **Mouse drag / Swipe** — Rotate camera
- **Mouse wheel** — Zoom
- **E / On-screen button** — Interact
- **Escape** — Pause
- **Mobile controls** — Touch joystick and interaction button
